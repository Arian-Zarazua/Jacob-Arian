# Game Analysis Workflow

## Step 1: identify teams and game
Confirm matchup and date.

## Step 2: extract key stats
yards, turnovers, scoring, possession.

## Step 3: evaluate game script
run vs pass balance, score effects.

## Step 4: compute efficiency
yards/play, TD rate, turnover impact.

## Step 5: interpret outcome
why team won or lost beyond score.
